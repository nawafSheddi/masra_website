---
name: add-client
description: Add a new client (project page at /work/<id>) to the MASRA website. Use when the owner wants to showcase a new client or project.
---

Follow `AGENTS.md`: **Recipes → Add a new client**. Before starting, ask the
owner for anything missing:

- client name
- category: Artistic, Lifestyle or Menu
- year, 2–4 tags, a one- or two-sentence description
- the photos: one main photo plus the gallery photos. How many depends on
  the layout: see the "Frames" column in AGENTS.md (e.g. theatrical needs
  exactly 3, strip 3–8)
- which existing client's look the new page should follow (offer 2–3
  layouts from the table in AGENTS.md)

Then copy the closest client file, import the photos with `media:add`, fill
every field, and run `npx pnpm check`. Preview the new page and the Work
grid, show screenshots, and ask before committing.
